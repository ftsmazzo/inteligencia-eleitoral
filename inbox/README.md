# inbox · RAW sujo

Despeje aqui dumps da outra aplicação, zips soltos, pastas fora de ordem.

Esta pasta **não é** `data/raw`. Nada daqui vira fato até alguém copiar, com SHA-256, para `data/raw/<id_base>/<data>/` segundo `data/README.md`.

## Agente / Cursor

Somente leitura. Proibido: editar, renomear, apagar, “organizar”, sobrescrever. Só listar e copiar para `data/raw` quando o arquivo for aproveitável.

## Conectar outra pasta no workspace?

Evite. Pasta adicionada ao workspace fica gravável para o agente. Se o dump já vive noutro disco, deixe **fora** do Cursor e copie o que for reusar para `inbox/` ou direto para `data/raw`. Se mesmo assim conectar: o risco de alteração existe; esta regra não substitui permissão de só leitura no sistema de arquivos.
