Dúvidas frequentes

        
O número veio vazio. É zero?
Não. Lista vazia significa que o dado não existe na base — não é zero votos.

        
Posso pedir resultado de 2026?
Só candidaturas (quem se inscreveu). Votos só depois da apuração oficial.

        
A IA pode estimar se faltar dado?
Não. Esta ferramenta proíbe inventar. Fora do recorte, a resposta é seca: dado inexistente.

        
É a ferramenta da campanha NE9?
Não. É o Brasil inteiro, produto separado, fontes TSE/IBGE/MDS/Câmara.
